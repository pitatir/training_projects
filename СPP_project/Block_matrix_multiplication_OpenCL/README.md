# Блочное умножение матриц с помощью OpenCL

Данный проект - лабораторная работа по дисциплине "Параллельные алгоритмы" первого семестра третьего курса.

## Описание проекта

Данный проект реализует блочное умножение матриц умножение матриц в стандарте OpenCL с учётом оптимизаций доступа к
локальной и глобальной памяти. В коде присутствуют фрагменты, предназначенные для сравнения скорости вычислений в
зависимости от выбранной платформы. Код оснащен комментариями, которые упрощают его понимание.

Ключевые особенности проекта:

* использование OpenCL.

## Требования

1. OpenCL SDK, подходящий вашему устройству:
    * Intel: [Intel OpenCL Runtime](https://www.intel.com/content/www/us/en/developer/tools/opencl/overview.html)
    * NVIDIA: [NVIDIA CUDA Toolkit](https://developer.nvidia.com/cuda-toolkit)

2. Драйверы GPU/CPU, поддерживающие OpenCL.

## Инструкция по запуску

В теории, запуск программы должен происходить следующим образом в директории ./src:

1. ```g++ main.cpp -o matrix_mul -lOpenCL```
2. ```./matrix_mul```

К сожалению, на практике с установкой необходимых для использования OpenCL библиотек возникли сложности -
их пришлось устанавливать самостоятельно с помощью msys2
и вручную указывать путь к скачанным файлам в ./src/CMakeLists.txt.
Если Вы столкнетесь с такой же проблемой, 
после установки необходимых файлов укажите путь к ним в строках 4 и 5 CMakeLists.txt и запустите проект с помощью IDE.
Данный проект запускался на ОС Windows с помощью IDE Clion c toolchain MinGW, 
что не требовало предварительной сборки проекта с помощью cmake.
