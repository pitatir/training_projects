# Учебные проекты

В репозитории собраны несколько проектов, которые были созданы за время обучения в вузе.

## Структура репозитория

Ниже перечислены все проекты, имеющиеся в репозитории. \
К проектам прилагаются README.md и отчеты, упрощающие понимание назначения программ.

```

│   │   └── IPC_signals                                       - сигналы

├── Graduation_thesis                                    Бакалаврская ВКР: ПО для калибровки хроматических аберраций
```
