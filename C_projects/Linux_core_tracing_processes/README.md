# Трассировка ядра Linux - порождение процессов, смена контекста, конкуренция

Данный проект - лабораторная работа по дисциплине "Операционные системы" второго семестра второго курса.

## Описание проекта

В текущей директории расположен [отчет](https://github.com/pitatir/training_projects/blob/main/C_projects/Linux_core_tracing_processes/Linux_core_tracing_processes_report.pdf), который содержит подробное описание
проекта.

**Ключевые особенности проекта:**

* использование инструмента ftrace,
* исследование работы ядра Linux с процессами.

## Инструкция по запуску

Код, а также bash-скрипты, используeмые в ходе выполнения лабораторной работы, расположены в папке ./src.
В папке ./src/logs собраны логи выполнения программ.
Из логов в этой папке или из тех же логов, приведенных в тексте отчета, можно узнать инструкции для запуска программ.

Запуск программ с кодом осуществляется стандартным образом:

1. ```gcc <название программы>.c -o <название исполняемого файла>```
2. ```./<название исполняемого файла>```

Выполнение трассировки ядра осуществляется посредством скрипта:

1. Перед запуском скрипта нужно:
    * Находясь в директории ./src, скомпилировать используемые в скрипте программы (понять, какие именно, можно по
      отчету):
      ```gcc <название программы>.c -o <название исполняемого файла>``` \
     _Например, ```gcc 1-father.c -o 1f```_
    * Изменить путь к исполняемому файлу с кодом - переменная _prog_ в строке 4;
    * Сохранить файл в кодировке Unix(LF);
    * Раздать права на выполнения скрипта: ```chmod +x <полный путь к скрипту>```;
2. ```sudo su``` - переход в режим суперпользователя для доступа к каталогу в п.2;
3. ```cd /sys/kernel/debug/tracing``` - переход в каталог,
   содержащий файлы для управления трассировкой ядра с помощью инструмента Ftrace;
4. ```<полный путь к скрипту>```  - запуск скрипта трассировки ядра. \
   _Например, ```/home/pitatir/LR7/src/ftrace.sh```_
