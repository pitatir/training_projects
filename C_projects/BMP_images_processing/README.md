# Обработка изображений в формате BMP 

Этот проект - курсовая работа по дисциплине "Программирование" второго семестра первого курса.

## Описание проекта

В текущей директории расположен [отчет](https://github.com/pitatir/training_projects/blob/main/C_projects/BMP_images_processing/Image_processing_report.pdf), который содержит подробное описание проекта.

**Ключевые особенности проекта:**

* работа с динамической памятью;
* работа с фалами формата BMP, выравнивание количества байтов изображения;
* реализация CLI для пользовательского взаимодействия;
* написание Makefile.

## Инструкция по запуску

В директории ./src:
1. ```make``` - сборка проекта;
2. ```./сw_bmp``` - вывод справки о приложении и его CLI.
