# Межпроцессные взаимодействия - каналы, сокеты, разделяемая память

Данный проект - лабораторная работа по дисциплине "Операционные системы" второго семестра второго курса.

## Описание проекта

В текущей директории расположен отчет _(IPC_pipe_fifo_sockets_shm.pdf)_, который содержит подробное описание проекта.

Ключевые особенности проекта:

* использование именованных и неименованных каналов;
* использование TCP и UDP сокетов;
* реализация разделяемой памяти и ее синхронизации.

## Инструкция по запуску

Код каждого задания лабораторной работы расположен в отдельной папке с номером задания в директории ./src.
Также в каждой такой папке лежит лог выполнения задания и необходимые для работы кода файлы.
Инструкции по запуску программы можно увидеть в первых строках лога, 
расположенного в папке с заданием или в тексте отчета.

В большинстве случаев это команды вида (иногда в разных терминалах):

1. ```gcc server.c -o s```
2.  ```./s```
3. ```gcc server.c -o s```.
4. ```./с```
