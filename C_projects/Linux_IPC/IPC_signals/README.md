# Межпроцессные взаимодействия - сигналы

Данный проект - лабораторная работа по дисциплине "Операционные системы" второго семестра второго курса.

## Описание проекта

В текущей директории расположен [отчет](https://github.com/pitatir/training_projects/blob/main/C_projects/Linux_IPC/IPC_signals/IPC_signals_report.pdf), который содержит подробное описание проекта.

**Ключевые особенности проекта:**

* реализация обработчиков сигналов, надежных и ненадежных сигналов;
* реализация сигналов реального времени;
* работа с очередью сигналов, их приоритетностью.

## Инструкция по запуску

Код каждого задания лабораторной работы расположен в отдельной папке с номером задания в директории ./src.
Также в каждой такой папке лежит лог выполнения задания.
Инструкции по запуску программы можно увидеть в первых строках этого лога, 
расположенного в папке с заданием или в тексте отчета.

В большинстве случаев это команды вида:

1. ```gcc _<Номер задания>_.c -o _<Номер задания>_```
2. ```./_<Номер задания>_```

_Например, для запуска кода пятого задания нужно в директории ./src/5 выполнить следующие команды:_

1. ```gcc 5.c -o 5```
2. ```./5```
